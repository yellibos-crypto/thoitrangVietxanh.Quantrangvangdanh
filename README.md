# Thời trang Việt xanh

Website giáo dục về thời trang xanh và bền vững cho Gen Z.
Đề án môn học Các ngành công nghiệp Văn hóa - Lĩnh vực Thời trang.

## Cấu trúc
- `index.html`: toàn bộ trang (HTML, CSS, JavaScript)
- `assets/`: ảnh nền trang đầu, áo, mây, logo (WebP)

## Chạy thử
Mở `index.html` bằng trình duyệt. Trang chỉ cần kết nối mạng để tải phông chữ Google Fonts.

## Đưa lên GitHub Pages
Settings > Pages > Source: Deploy from a branch > Branch: main, thư mục / (root).
